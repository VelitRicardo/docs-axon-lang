# AXON

**The language that compiles to LLMs.**

AXON is a cognitive runtime: a compiler and a type system for programs whose
executor is a language model. What most stacks postpone to runtime — which tools
an agent may reach, how much it may spend, what it must refuse to assert — AXON
checks while it compiles.
