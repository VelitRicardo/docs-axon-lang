<div className="ax-dropcap">
Most agent stacks postpone their hard questions to runtime. Which tools may this
agent reach? How much may it spend before it stops? What must it refuse to
assert when it cannot cite a source? AXON asks those questions at compile time,
because a property that is checked before the program runs is a guarantee, and
one that is checked while it runs is a hope.
</div>

The compiler, the type system and the runtime are open source. You can read
them, run them, and use them to contradict us — which is the point: a project
that sells guarantees cannot ask to be believed.

<CliBlock command="cargo install axon-lang" />

<Ledger columns={3}>
  <LedgerItem index="01" title="Guarantees, not intentions">
    Budgets, tool reach and epistemic obligations are declared in the source and
    verified by the compiler. What the type checker accepts, the runtime honours.
  </LedgerItem>
  <LedgerItem index="02" title="One language, two editions">
    The paid edition adds depth, never grammar. Any valid program parses and
    type-checks with the open-source compiler; what it cannot do is mount a
    capability it does not have — and it says so, by name, at compile time.
  </LedgerItem>
  <LedgerItem index="03" title="Rust and C, all the way down">
    A single toolchain with no runtime surprises. The compiler is Apache 2.0 and
    the runtime carries the LLVM exception, so your binaries owe nothing.
  </LedgerItem>
</Ledger>
