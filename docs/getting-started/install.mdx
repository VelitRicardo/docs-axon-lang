# Install

AXON ships as a single crate. One command:

```bash
cargo install axon-lang
```

## Requirements

The compiler and runtime are written in Rust, so installing from crates.io needs
a Rust toolchain. If you do not have one:

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

On Windows, use the installer from [rustup.rs](https://rustup.rs).

## Verify

```bash
axon --version
```

This documentation is written against **`axon-lang` v4.3.0**.
